# Three-minute demo script

## 0:00–0:25 — Problem

Production teams move quickly, but a plausible sentence can become a script line before anyone can trace where it came from. SceneLedger turns a production brief into a claim-by-claim evidence ledger.

## 0:25–0:55 — Brief

Load the independent-cinema example. Highlight the format, audience and information cutoff. Submit the brief.

## 0:55–1:25 — Runtime

Explain the visible sequence: Gemini 3.8 Flash plans the factual questions; Parallel Search retrieves live web evidence; Gemini synthesizes; deterministic code audits every citation.

## 1:25–2:10 — Ledger

Show supported, contested and unverified states. Open a source from the source roll. Explain that the system preserves uncertainty rather than converting every search result into a confident claim.

## 2:10–2:40 — Production decision

Use the production-use note to show how evidence changes a script line, interview plan or clearance task. Show open questions and risks.

## 2:40–3:00 — Proof

Show the audit badge and runtime metadata. End on the repository files that call `@google/genai` and `parallel-web`, then return to the product.
